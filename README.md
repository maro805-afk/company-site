### 特徴

- レスポンシブ対応(スマートフォン・タブレット・PC)
- 外部ライブラリ・ビルド工程は不要
- 単一ファイル(`index.html`)で動作

## ブラウザで index.html を開く手順

ビルドやサーバーの起動は不要です。以下のいずれかの方法で表示できます。

### 方法1: ダブルクリックで開く

1. エクスプローラー(Finderなど)でこのリポジトリのフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

### 方法2: ブラウザにドラッグ&ドロップする

1. ブラウザ(Chrome、Edge、Firefox、Safariなど)を起動します。
2. `index.html` をブラウザのウィンドウにドラッグ&ドロップします。

### 方法3: コマンドラインから開く

Windows(PowerShell):

```powershell
start index.html
```

macOS:

```bash
open index.html
```

Linux:

```bash
xdg-open index.html
```
